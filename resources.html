Research Resources

The following resources provided the technical data and historical context regarding the transition from Web 1.0 to modern responsive standards.

  • Web Design Museum - A visual gallery of the early internet, showcasing the table-based layouts discussed in Topic 1.

Modern Standards & UI/UX

  • MDN: Guide to Flexbox - The primary documentation used to understand modern alignment and fluidity.
  • W3C Accessibility Fundamentals - Resource for understanding the "Semantic Hierarchy" discussed in Topic 2.
  • Google Fonts Knowledge - Insights into how modern web typography replaced the limited web-safe fonts of the past.
