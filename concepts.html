Core Research Concepts

To understand the evolution of web design, one must understand the shift from fixed, hardware-constrained layouts to fluid, software-driven architectures.

Term Technical Context & Definition
Table-Based Layout A legacy design method where HTML <table> tags were used to create page columns. This was technically "incorrect" use of markup but necessary before CSS positioning existed.
Web-Safe Palette A standardized set of 216 colors used in the 90s to prevent "dithering" (grainy artifacts) on monitors that could only display 8-bit color.
Bandwidth Bottleneck The constraint caused by dial-up speeds (56kbps), which forced 90s designers to use text-heavy layouts and tiny, optimized GIF images.
Mobile-First Design A modern strategy where the website is designed for the smallest screen first, then scaled up for desktops, ensuring efficiency and speed on mobile networks.
CSS Flexbox & Grid Modern layout engines that allow elements to grow, shrink, and wrap automatically. This replaced the rigid tables of the past with total fluidity.
Semantic Hierarchy The practice of using HTML tags (like <main> or <article>) to define content meaning rather than just appearance, essential for modern accessibility (A11y).
