Core Web Research Concepts

This table defines the technical pillars that allowed the web to evolve from static pages to dynamic applications.

ConceptDetailed Definition
FlexboxA one-dimensional layout model that allows elements to align and distribute space within a container.
Semantic HTMLUsing tags like <header> and <main> to tell the browser what the content actually is.
Responsive DesignThe practice of building sites that work on desktops, tablets, and phones automatically.
Box ModelThe CSS standard that treats every element as a box with margins, borders, and padding.
GitHub PagesA hosting service that turns a GitHub repository into a live, public website.
