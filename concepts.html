Core Web Research Concepts

This glossary defines the technical pillars that allowed the web to evolve from static text pages to dynamic mobile applications.

ConceptDetailed Definition
FlexboxA one-dimensional layout model that allows elements to align and distribute space within a container automatically.
Semantic HTMLUsing tags like <header> and <main> to tell the browser what the content is, improving accessibility.
Responsive DesignThe practice of building sites that work on desktops, tablets, and phones from a single codebase.
Box ModelThe CSS standard that treats every element as a box with margins, borders, padding, and content.
Mobile-FirstA design strategy where you start with the mobile screen size and layer on complexity for larger monitors.
