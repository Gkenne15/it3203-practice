About the Web Evolution Project

This website was developed as a core research project for the IT 3203: Web Development course at Kennesaw State University. The primary goal is to provide a technical and visual timeline of how web standards have shifted over the last three decades.

By contrasting the static, table-driven layouts of "Web 1.0" with the fluid, mobile-first architectures of today, this site serves as an educational resource for understanding the relationship between hardware constraints (like bandwidth) and software design (like CSS Flexbox).

Milestone 2 Implementation & Technical Goals

During this phase of development, the project was upgraded from basic HTML structure to a fully functional web application. Key technical milestones include:

  • Interactive Scripting: Built a custom Vanilla JavaScript engine for the Quiz page to handle user inputs and dynamic DOM updates.
  • Design System: Refactored the CSS to use CSS Variables (Custom Properties) for consistent branding and improved code maintainability.
  • Image Optimization: Implemented a 50% maximum width rule for all media to ensure visual balance and readability across different screen sizes.
  • Academic Content: Expanded historical research to meet the 4-paragraph requirement for Topic pages, ensuring a rigorous analysis of web history.
