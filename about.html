About the Project & Author

Project Overview

This website was developed as part of the IT 3203: Web Development curriculum. The primary objective of this research project is to document the rapid transformation of web design standards. By comparing the table-based layouts of the 1990s (Web 1.0) with the responsive, mobile-first architectures of today, this site serves as an educational tool for understanding technical evolution in the digital age.

About the Developer

Name: Gavin Kennedy

I am an Information Technology student specializing in frontend development and user interface design. My academic interests include optimizing web performance for low-bandwidth environments and implementing accessible design patterns that follow W3C standards.

Milestone 2 Technical Implementation

For this phase of the project, I have implemented the following technical features to move from a static site to a dynamic frontend experience:

  • Dynamic Quiz Engine: Developed a custom JavaScript application that provides immediate grading and feedback for user assessments.
  • Refactored CSS: Optimized the global stylesheet using CSS Variables for consistent branding and improved accessibility.
  • Responsive Media: Corrected image scaling to a 50% box-model width to improve layout balance and readability.
  • Semantic HTML: Refined the document structure to use meaningful tags like <main>, <header>, and <section> for better SEO and screen-reader support.
